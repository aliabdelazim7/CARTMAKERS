# CartMakers — Full Social Content Pack

حزمة تسليم كاملة للاستخدام في Instagram وFacebook والحملات الإعلانية.

## المحتويات

- `02-posts-and-reels/`: الـ12 أصلًا بعد الـPinned Posts، بما يشمل الصور، الكاروسيلات، ملفات HTML المصدر، الفيديوهات، الصوت، وكابشن كل أصل.
- `03-final-reference-style-reels/`: الريلز الأربعة النهائية بأسلوب الفيديو المرجعي مع كابشن كل Reel.
- `INSTAGRAM_UPLOAD_GUIDE.md`: تعليمات الرفع، مقاسات الفيديو، ومكان نسخ الكابشن الجاهز.

تم استبعاد الـPinned Carousels من هذه النسخة لأنها نُشرت بالفعل.

## داخل كل Caption

- Hook قوي.
- `caption.txt` جاهز للنسخ واللصق مباشرة.
- CTA واحد واضح.
- نسخة قصيرة للحملات: Primary Text + Headline.
- Hashtags مناسبة.
- لا توجد عناوين Markdown أو ملاحظات تقنية داخل نص النشر.

## ملاحظة نشر

لا تنشر كل الأصول دفعة واحدة. استخدم 3 منشورات أسبوعيًا، واختبر الـHooks والنسخ الإعلانية حسب الحفظ، المشاهدة الكاملة، المشاركات، والرسائل ذات الجودة.

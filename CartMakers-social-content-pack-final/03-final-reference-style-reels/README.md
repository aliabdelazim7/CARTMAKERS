حزمة الريلز النهائية بأسلوب الفيديو المرجعي بعد اعتماد النموذج.

## الملفات

1. `01-commerce-diagnostic.mp4` — النموذج المعتمد: عندك زيارات ومفيش طلبات؟
2. `02-product-page-checklist.mp4` — صفحة المنتج قبل زيادة الإعلانات.

4. `04-platform-choice.mp4` — اختيار Shopify أو WooCommerce بناءً على طريقة البيع.

## النظام البصري والصوتي

- Editorial light background مع CartMakers Navy وElectric Lime.
- Objects وUI متحركة مرتبطة بموضوع كل Reel.
- Typography كبيرة وسريعة القراءة.
- Slide transitions سريعة وcontrolled zoom.
- Sound Effects عند نقاط التحول.
- صوت رجل مصري واحد، حماسي وواثق، بدون مبالغة إعلانية.
- كل الملفات بنسبة 9:16 وبترميز H.264/AAC.

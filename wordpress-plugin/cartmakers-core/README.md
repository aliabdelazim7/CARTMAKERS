# CartMakers Core

This companion plugin keeps CartMakers business data independent from the theme. It registers Portfolio Projects, Services and Testimonials, provides custom fields, global settings, a safe contact handler and a non-destructive content importer.

No paid plugin is required. A trusted SMTP plugin is recommended for reliable email delivery, but it is not required by the plugin code.

The plugin should be activated before the CartMakers theme. See `../wordpress-theme/cartmakers-theme/docs/INSTALLATION.md` for the full setup flow.
